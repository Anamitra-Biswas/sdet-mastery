# SDET Mastery Framework

> Production-grade test automation framework built with Java, Selenium, REST Assured, Cucumber, and AI-augmented testing tools.

## 🛠 Tech Stack
- **Language:** Java 17
- **Build Tool:** Maven
- **UI Testing:** Selenium WebDriver 4 + Page Object Model
- **Test Framework:** TestNG
- **API Testing:** REST Assured
- **BDD:** Cucumber with Gherkin
- **Reporting:** Allure Reports
- **CI/CD:** GitHub Actions
- **Infrastructure:** Docker + Selenium Grid
- **AI Testing:** LLM Test Generation · Self-Healing Locators · Visual AI Testing
